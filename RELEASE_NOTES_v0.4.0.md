# Local Edit 0.4.0

На `main` доступны исходники для UXP Developer Tool. Предыдущий CCX 0.2.2 остаётся в Releases; новый установщик в это обновление не входит.

- Добавлен Qwen Image 2.1 Turbo INT8: 8 шагов, без улучшателя промпта.
- В Qwen и Klein можно прикрепить до двух референсов. Слои вклеиваются по исходному выделению, без дополнительной растушёвки.
- FLUX.1 Fill берёт больше контекста, работает в 25 шагов, подгоняет цвет на стыке и смягчает маску слоя. Рост маски генерации ограничен для узкого лассо. При нескольких областях растушёвка идёт внутрь.
- Отдельные выделения обрабатываются последовательно во всех трёх режимах. Готовые слои не пропадают при остановке очереди.
- В панели есть прогрев модели и освобождение VRAM. Автозапуск ComfyUI под Windows включается настройкой локального пути.
