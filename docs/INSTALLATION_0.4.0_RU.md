# Local Edit 0.4.0: установка из исходников

В этой версии три режима: FLUX.1 Fill, FLUX.2 Klein и Qwen Edit 2.1 Turbo. Для 0.4.0 нужен UXP Developer Tool. Если нужен готовый установщик, [CCX 0.2.2](https://github.com/kuznetsovphotographer-prog/Flux-Local-Edit/releases/tag/v0.2.2) по-прежнему доступен, но в нём только Fill и Klein без новых изменений.

## Photoshop и ComfyUI

1. Нужен Photoshop **25.0** или новее. Скачайте архив в **Code → Download ZIP** и распакуйте его в постоянную папку.
2. Откройте [Adobe UXP Developer Tool](https://developer.adobe.com/photoshop/uxp/guides/). Выберите **Add Plugin**, укажите `plugin/manifest.json`, нажмите **Load**. В Photoshop откройте **Подключаемые модули → Local Edit**. При обновлении исходников сделайте **Unload → Load**. Workflow JSON вместо manifest не загружайте.
3. Установите [ComfyUI](https://docs.comfy.org/installation/install_comfyui), если его ещё нет. Запустите локальный экземпляр и проверьте, что он открывается по адресу `http://127.0.0.1:8188`. Для локальной работы не открывайте порт в интернет. Плагин сам отправляет workflow в ComfyUI, открывать его руками не нужно.

## Модели

Скачивайте только файлы для тех режимов, которыми собираетесь пользоваться. Пути ниже считаются от папки моделей вашего ComfyUI. После добавления весов обновите список моделей или перезапустите сервер.

- **FLUX.1 Fill и FLUX.2 Klein.** Имена весов и папки не изменились. См. [таблицу моделей](INSTALLATION_RU.md#models). Для предварительного заполнения и подгонки цвета по окружению в Fill можно установить [ComfyUI Inpaint Nodes](https://github.com/Acly/comfyui-inpaint-nodes). Без него плагин использует стандартные узлы, без этих двух этапов на стороне ComfyUI.
- **Qwen Image 2.1 Turbo.** Нужна версия ComfyUI с поддержкой [Qwen Image 2.1](https://docs.comfy.org/tutorials/image/qwen/qwen-image-2-1). Три файла ниже есть в [репозитории Comfy-Org](https://huggingface.co/Comfy-Org/Qwen-Image-2.1). BF16-веса основной модели и отдельный энкодер улучшателя промпта не нужны.

| Папка | Файл Qwen |
| --- | --- |
| `models/diffusion_models/` | `qwen_image_2.1_turbo_int8_convrot.safetensors` |
| `models/text_encoders/` | `qwen3vl_8b_int8_convrot.safetensors` |
| `models/vae/` | `qwen_image_2.1_vae_bf16.safetensors` |

## Первый запуск

1. Сделайте небольшое выделение и начните с **1 MP**. Для Klein нужен прямоугольник с **Feather 0**. Fill и Qwen принимают лассо.
2. Опишите правку. В Fill можно оставить поле пустым, чтобы модель продолжила окружение. В Klein и Qwen кнопка **Add reference** принимает до двух картинок. В Qwen в тексте на них можно ссылаться как на `<image2>` и `<image3>`.
3. Нажмите **Generate**. Для нескольких объектов добавляйте области с **Shift** и оставляйте между ними зазор. Каждый фрагмент сначала генерируется и вставляется, только затем запускается следующий. Результаты лежат на отдельных слоях в одной группе.

У одного выделения в Fill мягкая маска может немного выйти за контур. В нескольких областях Fill смягчает маски только внутрь. Klein и Qwen не добавляют растушёвку и скрывают результат за исходным контуром.

## Автозапуск и память

Если ComfyUI уже работает, плагин подключается к нему. Для ручного запуска настройка не нужна. Чтобы включить автозапуск под Windows для установки ComfyUI с `venv`, скопируйте `plugin/scripts/comfyui-path.example.txt` в той же папке под именем `comfyui-path.txt`. Замените пример абсолютным путём к папке, где лежат `main.py` и `venv\Scripts\pythonw.exe`. Одна строка, без кавычек, UTF-8 без BOM. При запросе UXP разрешите запуск локального файла.

В сборках со встроенным Python вместо `venv` запускайте ComfyUI штатным способом. Если автозапуск настроен, но сервер не отвечает, смотрите `comfy-launch.log` и `comfy-server.log` в `%LOCALAPPDATA%\LocalEdit`.

- Стрелка вниз запускает пробный прогон выбранной модели без правки открытого документа. Это прогрев, а не гарантия, что все веса останутся в VRAM.
- Стрелка вверх освобождает память **всех** моделей этого ComfyUI, только если очередь пуста. Сервер остаётся запущенным.
