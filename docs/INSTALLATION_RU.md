# Установка Flux Local Edit с нуля

Инструкция для версии 0.1.6. Основной путь описан для Windows и NVIDIA. Если ComfyUI уже работает, не устанавливайте второй экземпляр: проверьте адрес и модели, затем переходите к первому запуску.

Панель Photoshop и ComfyUI устанавливаются отдельно. Панель может открываться без ComfyUI, но генерация без сервера и моделей не начнётся.

<a id="requirements"></a>
## 1. Проверьте, что понадобится

- Photoshop 25.0 (2024) или новее. Проверенная автором конфигурация: Windows, portable Photoshop 27.8.
- Для обычной установки CCX: работающий Adobe Creative Cloud Desktop. Для разработки можно использовать UXP Developer Tool.
- Актуальный ComfyUI с поддержкой FLUX.1 Fill и FLUX.2 Klein.
- Достаточно места для ComfyUI и моделей. Итоговые семь файлов занимают десятки гигабайт; подготовка Fill из официальных весов временно требует ещё места для исходного файла около 24 GB и результата около 12 GB. Оставьте запас.
- Подходящая видеокарта, оперативная память и актуальный драйвер. Проверенный универсальный минимум VRAM для этой пары моделей не установлен. FP8 уменьшает объём весов, но не гарантирует работу на любой видеокарте. Начните с 1 MP, не с 4 MP.

Код UXP-панели не привязан только к Windows, но установка и генерация на macOS в этом релизе не проверены. Не обещаем работу на Mac без теста.

<a id="photoshop"></a>
## 2. Установите панель в Photoshop

### Обычный Photoshop с Creative Cloud

1. Скачайте [com.local.photoshop.flux-local-edit_PS.ccx](../ccx/com.local.photoshop.flux-local-edit_PS.ccx). На странице файла GitHub нажмите кнопку скачивания raw-файла. Не сохраняйте HTML-страницу вместо CCX.
2. Сохраните открытые документы и закройте Photoshop.
3. Дважды щёлкните CCX. Подтвердите установку в Creative Cloud Desktop. [Официальная установка Adobe](https://developer.adobe.com/uxp/guides/how-to/distribution/install/).
4. Запустите Photoshop заново.
5. Откройте **Подключаемые модули → Flux Local Edit → Flux Local Edit**. В английском интерфейсе: **Plugins → Flux Local Edit → Flux Local Edit**.

Если двойной щелчок не помог, скачайте весь репозиторий через **Code → Download ZIP**, распакуйте его и запустите `ccx/INSTALL_PLUGIN.bat`. Файл CCX должен лежать рядом с BAT. Скрипт использует официальный установщик Adobe, запрашивает права администратора и запускает его из `C:\`. Creative Cloud и UPIA всё равно должны быть установлены. Этот BAT не является установщиком для portable-сборки.

После установки через UPIA тоже полностью перезапустите Photoshop. Одна надпись Installed ещё не подтверждает, что нужная копия Photoshop увидела панель.

### Через UXP Developer Tool

Подходит для исходников и разработки, если UDT уже доступен. [Инструменты разработчика Adobe](https://developer.adobe.com/uxp/guides/how-to/developer-tools/).

1. Скачайте ZIP всего репозитория и распакуйте в постоянную папку, например `C:\FluxLocalEdit`.
2. В Photoshop откройте **Правка → Установки → Подключаемые модули** и включите режим разработчика, если он требуется вашим UDT. Перезапустите Photoshop.
3. Запустите Photoshop и UXP Developer Tool.
4. Нажмите **Add Plugin** и выберите **plugin/manifest.json**.
5. Нажмите **Load**, затем откройте панель через меню Photoshop.

Нельзя выбирать workflow JSON из папки workflows. Ошибка Invalid Manifest File означает, что выбран не manifest плагина либо повреждён сам manifest. Не загружайте две копии одного ID одновременно: перед установкой CCX выгрузите dev-копию через Unload.

### Portable Photoshop без Creative Cloud

Не копируйте CCX в обычную папку Plug-ins: UXP работает иначе. Для конкретного лаунчера `C:\Photoshop\PhotoshopPortable.exe` подготовлена [отдельная инструкция](PORTABLE_RU.md). Она не универсальна для всех portable-сборок. Для другой сборки сначала нужно найти её UXP-хранилище и способ регистрации.

<a id="comfyui"></a>
## 3. Установите и запустите ComfyUI

Ниже используется официальный portable-пакет ComfyUI для Windows. Он не связан с portable Photoshop и не изменяет Photoshop.

1. Откройте [официальную инструкцию ComfyUI Portable](https://docs.comfy.org/installation/comfyui_portable_windows). Выберите сборку для своей видеокарты. Для NVIDIA используйте подходящий пакет NVIDIA, учитывая требования текущей сборки к драйверу.
2. Скачайте архив. Распакуйте его полностью, например в `C:\AI\ComfyUI_windows_portable`. При необходимости используйте 7-Zip. Не запускайте BAT прямо из архива.
3. В распакованной папке найдите `run_nvidia_gpu.bat` и запустите его. Python уже входит в пакет, отдельно устанавливать его для этого пути не нужно.
4. Дождитесь в консоли адреса `http://127.0.0.1:8188`. Откройте его в браузере, если браузер не открылся сам.
5. Не закрывайте консоль ComfyUI во время генерации.

Плагин 0.1.6 использует фиксированный адрес `http://127.0.0.1:8188`. Если другой экземпляр работает на 8189 или Desktop выбрал другой порт, это не тот сервер. Для этой инструкции используйте один экземпляр на 8188. Не открывайте порт в интернет и не включайте `--listen 0.0.0.0` для работы на одном компьютере.

Если ComfyUI установлен через Stability Matrix, запускайте существующий пакет там. Папки моделей могут быть общими или подключёнными через `extra_model_paths.yaml`. Проверяйте доступность имён через ComfyUI, а не только наличие файлов на диске. Сначала сохраните настройки перед их изменением.

Для AMD/Intel используйте официальную инструкцию соответствующей сборки, а не NVIDIA BAT. Эти варианты для данного плагина отдельно не тестировались.

<a id="models"></a>
## 4. Скачайте модели и положите в нужные папки

Для Fill нужны четыре файла, для Edit три. Для работы обоих режимов нужен весь список. На Hugging Face откройте **Files and versions**, выберите нужный файл и нажмите Download. Не скачивайте весь репозиторий модели и не загружайте diffusers-папки вместо одиночного `.safetensors`.

Для gated-моделей BFL понадобится аккаунт Hugging Face и принятие условий модели. Ошибка 401/403 обычно означает отсутствие доступа; это не ошибка Photoshop.

| Режим | Точное имя файла для плагина | Папка внутри ComfyUI | Откуда взять |
| --- | --- | --- | --- |
| Fill | `flux1-fill-dev-fp8.safetensors` | `models/diffusion_models/` | Официальный [FLUX.1 Fill Dev](https://huggingface.co/black-forest-labs/FLUX.1-Fill-dev/tree/main), затем подготовка FP8 ниже |
| Fill | `clip_l.safetensors` | `models/text_encoders/` | [Текстовые энкодеры FLUX](https://huggingface.co/comfyanonymous/flux_text_encoders/tree/main) |
| Fill | `t5xxl_fp8_e4m3fn.safetensors` | `models/text_encoders/` | [Текстовые энкодеры FLUX](https://huggingface.co/comfyanonymous/flux_text_encoders/tree/main) |
| Fill | `ae.safetensors` | `models/vae/` | [Официальный FLUX.1 Fill Dev](https://huggingface.co/black-forest-labs/FLUX.1-Fill-dev/tree/main) |
| Edit | `flux-2-klein-9b-fp8.safetensors` | `models/diffusion_models/` | [Официальный Klein 9B FP8](https://huggingface.co/black-forest-labs/FLUX.2-klein-9b-fp8/tree/main) |
| Edit | `qwen_3_8b_fp8mixed.safetensors` | `models/text_encoders/` | [Энкодер Klein 9B от Comfy-Org](https://huggingface.co/Comfy-Org/vae-text-encorder-for-flux-klein-9b/tree/main/split_files/text_encoders) |
| Edit | `flux2-vae.safetensors` | `models/vae/` | [VAE Klein от Comfy-Org](https://huggingface.co/Comfy-Org/vae-text-encorder-for-flux-klein-9b/tree/main/split_files/vae) |

Это имена из конфигурации плагина, а не произвольные рекомендации. **Klein 4B, base 9B, GGUF и другие энкодеры не являются заменой для этого релиза.** Изменение модели в открытом браузерном workflow не меняет граф, который отправляет плагин.

### Как подготовить Fill FP8 из официального файла

Официальный файл `flux1-fill-dev.safetensors` и нужный плагину `flux1-fill-dev-fp8.safetensors` не равнозначны. Переименование не меняет точность весов.

Самый воспроизводимый путь без случайных перепаковок:

1. Скачайте официальный одиночный `flux1-fill-dev.safetensors` в `C:\AI\Downloads`. Исходник занимает около 24 GB.
2. Скачайте весь пакет публикации, чтобы был доступен `tools/convert_fill_fp8.py`. В примере ниже пакет распакован в `C:\FluxLocalEdit`.
3. Закройте генерации ComfyUI на время подготовки. Откройте PowerShell и выполните:

```powershell
& "C:\AI\ComfyUI_windows_portable\python_embeded\python.exe" "C:\FluxLocalEdit\tools\convert_fill_fp8.py" "C:\AI\Downloads\flux1-fill-dev.safetensors" "C:\AI\ComfyUI_windows_portable\ComfyUI\models\diffusion_models\flux1-fill-dev-fp8.safetensors"
```

4. Дождитесь сообщения `Saved`. Скрипт переводит веса в unscaled FP8 E4M3 на CPU, сохраняет ключи/формы и проверяет контейнер. Он не меняет исходник и откажется перезаписывать уже существующий выходной файл. Нужен Python именно из ComfyUI с torch и safetensors, а не случайный системный Python.
5. Результат будет около 12 GB. Квантование может немного изменить качество по сравнению с исходными весами. Полный цикл генерации именно с заново сконвертированным официальным файлом пока не проверен автором; первый небольшой Fill-тест обязателен. Если у вас уже есть рабочий FP8-файл, конвертация не нужна.

Скрипт обрабатывает веса по одному тензору, но запас RAM и диска всё равно нужен. При ошибке он удаляет только собственный временный `.partial`, исходный файл остаётся. `ModuleNotFoundError` означает, что выбран не Python ComfyUI либо его окружение повреждено. Не устанавливайте зависимости в системный Python наугад.

### Итоговая структура папок

```text
ComfyUI_windows_portable/
  ComfyUI/
    models/
      diffusion_models/
        flux1-fill-dev-fp8.safetensors
        flux-2-klein-9b-fp8.safetensors
      text_encoders/
        clip_l.safetensors
        t5xxl_fp8_e4m3fn.safetensors
        qwen_3_8b_fp8mixed.safetensors
      vae/
        ae.safetensors
        flux2-vae.safetensors
```

Не кладите эти файлы в `checkpoints`. Не добавляйте вложенную папку с названием модели: для текущей конфигурации важно, чтобы ComfyUI видел именно указанные имена без префикса каталога. После копирования моделей полностью перезапустите ComfyUI.

<a id="workflow"></a>
## 5. Какой шаблон нужен в ComfyUI

**Для работы из Photoshop скачивать внешний шаблон не обязательно.** Плагин сам строит API-граф Fill и использует комплектный граф Edit. Браузерный canvas ComfyUI может оставаться пустым.

Если хотите проверить ComfyUI отдельно от Photoshop:

- Для Edit перетащите в ComfyUI комплектный [image_flux2_klein_image_edit_9b_distilled.json](../workflows/image_flux2_klein_image_edit_9b_distilled.json). Выберите нужные модели в загрузчиках и свою картинку в Load Image; проверьте обе ветки, если используете Reference. Это UI-workflow, не UXP manifest.
- Для Fill в библиотеке шаблонов найдите **Flux.1 Inpaint**. Порядок работы и официальный пример есть в [инструкции ComfyUI Fill](https://docs.comfy.org/tutorials/flux/flux-1-fill-dev). Официальный пример может использовать полноточный Fill и T5 FP16; для проверки вашей FP8-конфигурации выберите установленные файлы в Load Diffusion Model, DualCLIPLoader и Load VAE. Загрузите изображение, нарисуйте маску через Mask Editor и запустите граф.
- Для Klein правильное семейство шаблона: **Flux.2 Klein 9B Distilled / Image Edit**. [Официальный разбор ComfyUI](https://docs.comfy.org/tutorials/flux/flux-2-klein).

Плагин использует core-ноды. Не нужно устанавливать случайные наборы custom nodes по старым видео. Если нет Flux2Scheduler, ReferenceLatent, DifferentialDiffusion или InpaintModelConditioning, проверьте обновление ComfyUI и ошибки импорта в его консоли. Сохраните рабочую конфигурацию перед обновлением.

<a id="first-run"></a>
## 6. Первая генерация в Photoshop

### Fill

1. Запустите ComfyUI на 8188. Сначала убедитесь, что его страница открывается в браузере.
2. Откройте фотографию в Photoshop. Для первого теста используйте RGB 8 bit, обычный небольшой участок и сохранённую копию документа.
3. Лассо выделите деталь вместе с небольшим запасом по краям. Не выделяйте всю фотографию, если хотите исправить маленькую складку.
4. Откройте Flux Local Edit. Нажмите на весь блок с названием режима и модели, выберите **Fill / FLUX.1 Fill Dev FP8**.
5. Выберите **1 MP**.
6. Напишите, что должно быть на месте выделения. Например: `Smooth gray trouser fabric, matching the surrounding texture and lighting.` Или для удаления лампы: `Dark wooden wall matching the surrounding background, without a lamp.`
7. Нажмите **Generate** и дождитесь нового слоя. Во время обработки кнопка позволяет остановить запрос.
8. Сравните новый слой с оригиналом через значок глаза. В Fill исходная форма выделения становится маской слоя; при необходимости поправьте маску, цвет или непрозрачность.

Модель видит выделение с окружением, а не автоматически весь PSD: используется context crop с 20% отступом, ограниченным 64–512 px и границами холста. Для нескольких островков создаются общая маска, один запрос и один итоговый слой.

Пустой Prompt разрешён, но это заполнение по окружению, не гарантированное удаление. Модель может добавить нежелательную деталь. Для точной задачи предпочтительнее описать желаемый результат. Для предсказуемого первого теста используйте короткий запрос на английском; качество понимания русского не гарантируется.

### Edit

1. Выберите **Edit / FLUX.2 Klein 9B FP8**.
2. Используйте **Прямоугольную область** без растушёвки. Соотношение сторон может быть произвольным, но выделение должно быть сплошным прямоугольником внутри холста.
3. Напишите инструкцию, например `Make the jacket black, preserve its shape and the lighting.`
4. При необходимости подключите Reference и выберите изображение. Для первого теста удобнее PNG или JPEG.
5. Начните с 1 MP и нажмите Generate. Результат заменяет прямоугольный участок новым выровненным слоем. Маска лассо, как в Fill, для этого режима не реализована.

Reference хранится только в текущей сессии панели. После её закрытия/перезапуска выберите файл заново.

### Расширение фотографии через Fill

Сначала увеличьте холст средствами Photoshop. Подготовьте в документе незаполненную область рядом с существующей фотографией, затем выделите её с небольшим перекрытием оригинального края и используйте Fill. Плагин сам не увеличивает холст; результат зависит от доступного окружения. Сложная архитектура может достраиваться с ошибками.

<a id="actions"></a>
## 7. Две горячие клавиши через Actions

Прямого назначения произвольной клавиши UXP-панели здесь нет. Используются Photoshop Actions.

1. Откройте **Окно → Операции** / **Window → Actions**.
2. Создайте новую операцию, например `Flux Local Edit - Fill`, назначьте доступную функциональную клавишу с нужными модификаторами и включите запись.
3. Подготовьте выделение, выберите Fill, запрос и MP. Один раз запустите Generate. Остановите запись.
4. Создайте вторую операцию для Edit и назначьте другую функциональную клавишу.
5. Проверьте обе операции на копии документа, особенно воспроизведение в вашей версии Photoshop.

Записываются режим, текст запроса, MP и фактический seed. Поэтому операция воспроизводит сохранённые параметры, а не обязательно текущий текст в панели. Reference в операцию не записывается. Два обработчика и автотесты есть, но сценарии Actions/горячих клавиш требуют отдельной проверки в вашем Photoshop и не заявлены как полностью проверенные на всех версиях.

<a id="troubleshooting"></a>
## 8. Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Photoshop не видит плагин | Версию 25.0+, полный перезапуск, установку CCX, отсутствие dev-копии того же ID. Для portable проверьте именно её регистрацию, а не системную UXP-папку. |
| CCX не открывается | Скачан ли raw-файл, работает ли Creative Cloud. Альтернатива для обычной установки: BAT рядом с CCX. Журналы UPIA: `C:\ProgramData\Adobe\UPI\Log\Upia.log` и `EMCL.log`. |
| Invalid Manifest File в UDT | Выберите `plugin/manifest.json`, не workflow JSON. Не выбирайте CCX в Add Plugin. |
| Не соединяется с ComfyUI | Открывается ли `http://127.0.0.1:8188`, работает ли консоль, не занят ли порт другим процессом. Плагин не запускает сервер за вас. |
| Missing Fill models / Value not in list | Проверьте точные имена всех нужных файлов, их папки, отсутствие вложенного префикса. Перезапустите ComfyUI. |
| Missing nodes | Обновите ComfyUI после сохранения рабочей конфигурации; проверьте ошибки импорта в консоли. |
| Edit не принимает лассо | Используйте сплошной прямоугольник или переключитесь в Fill. |
| CUDA out of memory | Начните с 1 MP, закройте другие GPU-задачи, дождитесь завершения очереди. При необходимости перезапустите ComfyUI. Не заменяйте модель на GGUF без адаптации графа. |
| Долго нет результата | Первое чтение модели с диска занимает время. Проверьте очередь/консоль ComfyUI. В рекламных видео это ожидание вырезано. |
| Цвет или края не совпадают | Попробуйте другой запрос/выделение, повторите генерацию, поправьте маску и цвет кривыми или уровнями. Идеальное совпадение не гарантируется. |
| Fill добавляет лишнее при пустом запросе | Опишите желаемое содержимое. Пустой запрос не является специальной командой удаления. |
| Модель не выгрузилась при переключении | Выбор режима меняет следующий граф, а не немедленно память GPU. ComfyUI управляет загрузкой и освобождением памяти. |

Когда просите помощь, сообщите: Photoshop и его версию, Windows, способ установки, Fill/Edit, адрес ComfyUI и полный текст ошибки. Сделайте скриншот без личных файлов. Если панель открывается, но не генерирует, это обычно другой этап, чем установка CCX.

Панель бесплатна для скачивания и не вызывает платный API. Но лицензии моделей действуют отдельно. Используемые Fill Dev и Klein 9B имеют non-commercial условия для весов; разрешения на результаты описаны отдельно. Перед коммерческим применением сверяйтесь с [актуальной лицензией Fill](https://huggingface.co/black-forest-labs/FLUX.1-Fill-dev/blob/main/LICENSE.md), [лицензией Klein 9B](https://huggingface.co/black-forest-labs/FLUX.2-klein-9b-fp8/blob/main/LICENSE.md) и [BFL Licensing](https://bfl.ai/licensing). Это не юридическая консультация.

При localhost-подключении плагин передаёт изображения вашему ComfyUI, не облачному генератору. ComfyUI сохраняет загруженные изображения и результаты в своих input/output-папках: локальная обработка не означает отсутствие следов на диске. Вы самостоятельно контролируете эти файлы и сторонние расширения ComfyUI. Не используйте фотографии людей без необходимых прав и согласий.

Ссылки на внешнюю документацию проверены 30 сентября 2026 года. Внешние интерфейсы и условия могут меняться. Эта инструкция соответствует коду 0.1.6; её примеры путей нужно заменить на ваши реальные папки.
