# Flux Local Edit 0.1.6

Отдельная панель Photoshop для локальной работы с ComfyUI. Не заменяет старый Flux2 Klein.

## Возможности

- Fill: FLUX.1 Fill Dev FP8, контекст вокруг выделения, маска лассо/растушёвки/нескольких областей, один новый слой с исходной маской.
- Edit: FLUX.2 Klein 9B FP8, прямоугольное выделение, запрос и необязательный session-only Reference.
- Выбор режима через весь блок заголовка, двухстрочные пункты с названием модели, внутренняя синяя рамка активного пункта.
- Независимые запросы режимов, размер генерации 1–4 MP, остановка запроса.
- Два обработчика Photoshop Actions для Edit/Fill.

## Совместимость

Manifest: Photoshop 25.0+. Рабочая конфигурация автора: Windows и portable Photoshop 27.8. Установка этой portable-сборки описана отдельно. macOS, другие portable-лаунчеры и все сценарии Actions не проверены.

## Ограничения

Edit не поддерживает лассо в этом релизе. Пустой Fill не гарантирует удаление. Возможны сдвиг цвета, швы и изменения деталей. Минимум VRAM без измерений не заявлен. Выбор режима не вызывает принудительную выгрузку модели из GPU.
